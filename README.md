# Job Application Tracker

A web application for tracking internship and job applications. Built with Flask, SQLite, HTML, CSS, and JavaScript.

## Technologies

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript
* Git/GitHub

## Features

* Add job applications
* View saved applications
* Edit existing applications
* Delete applications with confirmation
* Track application status
* Dashboard statistics for:

  * Total applications
  * Interviews
  * Offers
  * Rejected applications
* Filter applications by status
* Search applications
* Sort applications by newest or oldest application date
* Color-coded application statuses
* Responsive application interface

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/AnthonyLoera10/job-application-tracker.git
```

2. Navigate into the project:

```bash
cd job-application-tracker
```

3. Start the Flask application:

```bash
python3 app.py
```

4. Open the application in your browser:

```text
http://127.0.0.1:5000
```
